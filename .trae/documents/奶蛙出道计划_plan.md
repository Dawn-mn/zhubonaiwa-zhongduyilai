  2. **结局规模 = 10 个核心结局**，覆盖 PRD 的 9 大方向，其中 2 个按隐藏条件触发；图鉴按 10 个实现，配置中预留后续扩到 16 的结构。

## 二、技术方案总览

- **纯静态网页，零构建**：`index.html` + `css/style.css` + 多个经典 `<script>`（不用 ES Module，保证双击 `file://` 也能运行；本地用静态服务器预览）。
- 移动端优先（内容容器最大宽 480px，桌面端居中），全部中文文案，黄/奶油/橄榄绿配色，圆润荒诞风格。
- 所有数值、条件、文案、素材映射均在 `js/config/` 配置中；引擎是唯一做数值结算的地方，UI 只读结果。
- 配置文件同时可被 Node 加载（UMD-lite 写法），供命令行数值模拟使用。

## 四、核心规则设计概要（细节落在配置表）

### 4.1 属性
- 0–100：热度、内容能力、路人缘、粉丝忠诚度、精力状态、商业价值（初值约 10/15/50/20/80/5）。
- 数值型：粉丝量（初值 128，显示 k/万）、现金（初值 ¥200，可为负但触发资金危机事件，不锁死游戏）。
- 全部变化经 clamp；精力 ≤25 时行动收益衰减且疲劳事件权重升高；低精力不在中途判死，只影响结局。

### 4.2 六动作（每动作：基础值 + 随机区间 + 属性缩放 + 精力消耗）
1. **短视频创作**：热度↑、粉丝中量↑、内容 +2，精力 −12；内容越高波动上限越高。
2. **直播**：现金↑（按粉丝/热度缩放）、忠诚度 +5、粉丝少量↑，精力 −18；有冷场风险。
3. **才艺训练**：内容 +8~12，精力 −8，短期热度 −2（长期投资）。
4. **品牌赞助**：粉丝达门槛才可选；现金 +150~400、商业价值 +6，路人缘/忠诚度下降，有翻车风险事件。
5. **休息**：精力 +22~30、热度 −3，可触发回血/灵感事件。
6. **全网玩梗**：高方差（热度 −8~+25），精力 −10；高热度低路人缘时争议概率升高；累积隐藏标记。

### 4.3 阶段与回合
5 阶段（1–3/4–7/8–14/15–21/22–30 天），每阶段 2 回合、每回合 2 动作；回合末一句小结，阶段末弹过渡层（「几天后」时间跳跃 + 表现分档总结）。日期由阶段/回合映射，不写死在事件里。

### 4.4 事件
- 6 类：日常 / 流量 / 商务 / 舆论 / 状态 / 隐藏；声明式条件（允许阶段、属性上下限、历史标记、动作次数、是否签约等）+ 权重 + once/冷却回合数。
- 每次动作后按权重抽取 0~1 个事件；关键事件（MCN、大爆红、重大争议）走带选项弹窗并写历史标记。
- 关键决策 **MCN 签约**：进入第 3 阶段且粉丝达门槛时触发；接受 = 资源/赞助收益 +30% 但精力代价上升、争议风险上升；拒绝 = 忠诚度/路人缘上升、玩梗爆红权重上升；满足「从未接高风险商务 + 路人缘 ≥60」时出现第三选项「独立工作室软合作」。不锁定结局，只改变权重与结局文案。

### 4.5 十个结局（按判定优先级从高到低，条件将在模拟后微调）
1. **电量耗尽·被迫休战**（疲惫路线，精力极低/过劳标记）
2. **黑红也是红·舆论中心**（争议路线，争议标记 + 高热度低路人缘）
3. **抽象之神·永恒的齁齁齁**（隐藏·梗王：玩梗次数 + 大爆红 + 忠诚度组合）
4. **田园归隐蛙**（隐藏：休息次数多 + 高路人缘 + 低热度）
5. **顶流·万蛙之上**（粉丝/热度/内容高、路人缘合格、无重大争议）
6. **蛙布斯榜·商业大亨**（商业路线：现金 + 商业价值）
7. **自己人·忠粉养成**（忠粉路线：忠诚度 + 粉丝基本盘）
8. **泼天富贵·一条视频的奇迹**（意外爆红路线：突发爆红标记 + 热度）
9. **小有所成·稳稳的幸福**（平稳路线：中游数据兜底）
10. **互联网没有记忆**（普通兜底结局）

每个结局配：AI 场景图、名称、一句总结、3 项本局关键数据、图鉴未解锁提示语。

## 五、实施步骤（依赖顺序）

1. **骨架**：建目录、`index.html` 四个界面外壳、`style.css` 基础样式与主题变量。
2. **配置层**：attributes → scenes（含素材登记表）→ actions → phases → events → endings，数值表全部落配置。
3. **素材落地**：下载奶蛙主图（先试 `milkyfrog.com` 直链，备选 doubaocdn 图床）；用指定 text_to_image 接口生成并保存 10 张结局图（统一风格后缀词保证一致性）；在 scenes.js 登记来源/授权「待确认」。
4. **引擎**：状态机、动作结算（唯一数值出口）、事件抽取、阶段推进、MCN 决策、结局优先级判定；写 `tools/sim.js` 跑模拟调平衡。
5. **UI 接线**：首页 → 运营页（属性条/剩余行动次数/场景舞台/结果文案与飘字）→ 事件弹窗 → 阶段过渡层 → MCN 抉择 → 结局页。
6. **图鉴与分享**：localStorage 解锁记录（含降级提示）、图鉴网格（已解锁看全、未解锁看提示）、canvas 结局卡导出/系统分享/复制链接降级。
7. **重开与边界**：一键重开完整重置；赞助门槛禁用提示；属性上下限；负现金不卡死。
8. **验证与修缺陷**（见下）。

## 六、验证方案

- **数值模拟（Node）**：`tools/sim.js` 用随机策略 + 4 种典型策略（狂发视频、均衡、玩梗流、休息养老流）各跑 ≥1000 局：
  - 10 个结局全部可达，无结局 0 触发、无单一结局概率畸高；
  - 无 NaN/undefined、属性恒在上下限内、现金不会卡死流程；
  - 不存在明显单一最优解：不同策略的优势结局不同。
- **浏览器实测**（静态服务器 + 浏览器工具）：
  - 完整打穿一局：20 动作、事件弹窗、MCN 三选一、阶段过渡、结局页；
  - 控制台无报错；动作前后属性变化可见；
  - 结局解锁 → 图鉴出现 → 刷新页面仍保留 → 再开一局状态正确重置；
  - 结局卡：图片/文案/数据正确，PNG 导出或分享降级可用；
  - 移动端视口（375px）与桌面端布局正常；
  - 素材加载失败时显示「素材待确认」角标而非错位。

## 七、风险与处理

- **真实素材防盗链/下载失败**：准备 2–3 个候选 URL；下载失败则页面热链 + `<img onerror>` 降级占位角标；scenes.js 中如实标「来源待确认，仅限原型验证，禁止商用」。
- **AI 结局图风格漂移**：10 条 prompt 共用固定角色描述与画风后缀；成品不要求完全一致，但保黄/梨形/凸眼狂笑特征。
- **canvas 导出被跨域图片污染**：图片优先本地同源存放；若接口图无法预下载，则导出降级为纯绘制版卡片 + 复制文案，不影响截图分享主路径。
- **环境不支持 localStorage**：storage 层探测并在图鉴入口显示小字提示，不假装保存。
- **数值不平衡/多结局同触发**：结局严格按优先级判定；阈值用 sim 结果校准并集中在 endings.js 顶部常量，便于后续调整。
- **范围控制**：不做账号、联网、排行榜、付费、音频；新增内容只进配置，不改核心流程。
